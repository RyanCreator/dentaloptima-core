                 Clinical Data Set validation

   FP17 and FP17W submissions must include at least one Clinical Data Set (CDS) item
   relating to the band of treatment claimed.
   For example, an FP17 for a Band 2 treatment must include at least one CDS item that
   relates to Band 2 treatment item, such as an extraction. If the submission contained only
   Band 1 CDS items, or if it included Band 3 CDS items this would be incorrect.
   Incorrectly submitted FP17s will receive one of the following comment codes:

       · 011 ­ if no CDS items matching the band of treatment claimed are present.
       · 012 ­ if CDS item relating to a higher band of treatment than claimed are present.
       · 013 ­ if a `Regulation 11' FP17 is submitted without a relevant CDS item.
       · 014 ­ if a `Free Repair/Replacement' FP17 is submitted without a relevant CDS

            item.
   This document outlines the CDS items relating to each band of treatment.
   England and Wales have different CDS items, select the country below to jump to the
   relevant section:
